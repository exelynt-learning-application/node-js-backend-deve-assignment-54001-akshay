# Mini Web Server Project

## 1. Objective

The objective of this project is to create a small HTTP server using Node.js. The server supports multiple routes, returns JSON responses, handles invalid routes with a `404` status code, and uses proper HTTP status codes.

## 2. Project Structure

```text
mini-web-server/
│
├── server.js
└── package.json
```

## 3. server.js

```javascript
const http = require("http");

const PORT = 3000;

const server = http.createServer((req, res) => {
    res.setHeader("Content-Type", "application/json");

    // Home route
    if (req.method === "GET" && req.url === "/") {
        res.statusCode = 200;

        res.end(JSON.stringify({
            message: "Welcome to the Mini Web Server"
        }));
    }

    // About route
    else if (req.method === "GET" && req.url === "/about") {
        res.statusCode = 200;

        res.end(JSON.stringify({
            message: "This is the About page",
            technology: "Node.js"
        }));
    }

    // Users route
    else if (req.method === "GET" && req.url === "/users") {
        res.statusCode = 200;

        res.end(JSON.stringify({
            users: [
                {
                    id: 1,
                    name: "Akshay"
                },
                {
                    id: 2,
                    name: "Rahul"
                }
            ]
        }));
    }

    // Health check route
    else if (req.method === "GET" && req.url === "/health") {
        res.statusCode = 200;

        res.end(JSON.stringify({
            status: "OK"
        }));
    }

    // Invalid route
    else {
        res.statusCode = 404;

        res.end(JSON.stringify({
            error: "Route not found"
        }));
    }
});

server.listen(PORT, () => {
    console.log(`Server is running at http://localhost:${PORT}`);
});
```

## 4. package.json

Create a `package.json` file:

```json
{
  "name": "mini-web-server",
  "version": "1.0.0",
  "description": "A simple Node.js HTTP server",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  }
}
```

## 5. How to Run

Open the terminal inside the project folder.

Run:

```bash
npm start
```

You should see:

```text
Server is running at http://localhost:3000
```

You can also run:

```bash
node server.js
```

## 7. HTTP Status Codes Used

| Status Code | Meaning | Usage |
|---|---|---|
| 200 | OK | Successful requests |
| 404 | Not Found | Invalid or unknown route |
